# Public Disclosure

This repository is exclusively a public case study for the MedulaSport Timing Platform.

It does not contain the proprietary project source code. The implementation remains private due to client and project confidentiality.

The repository deliberately omits:

- Authentication material and sensitive configuration.
- Production infrastructure details.
- Internal server paths.
- Participant personal data.
- Real competition records.
- Real operational backups.
- Database dumps.
- Android signing material.
- The production APK.

Visual material uses original diagrams, public context, fictitious data or anonymised representations. Security and operational details have been intentionally reduced for client and system confidentiality.
